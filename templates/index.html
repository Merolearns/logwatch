logwatch

Paste or upload a web server access log (Apache/Nginx combined format) and get a traffic + security report: request totals, status codes, top IPs and paths, an hourly chart, and flags for scanners, attack probes, and one-off user agents. Nothing is stored — the log is analyzed in memory and forgotten.

What it checks

  • Traffic — total requests, unique IPs, status code breakdown, busiest paths and busiest hours.
  • Scanners — an IP returning 50+ 404s, or firing 500+ requests inside any 60-second window.
  • Attack probes — requests matching naive signatures (UNION SELECT, ../, <script>), flagged for a human to review.
  • One-off user agents — agents seen exactly once, usually bots or one-off scripts.

Lines that don't look like combined-format entries are counted as skipped, not silently dropped. The sample log is 90 lines of hand-written traffic with a scanner and three attack probes baked in.
